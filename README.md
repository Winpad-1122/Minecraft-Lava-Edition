# Minecraft: Lava Edition

A C# WinForm program to simulate lava in Minecraft.

## Features

- **3D preview**: Real-time display of changes of lava.
- **Version support**: Supports versions from Java Infdev 20100616 to now.
- **Render iInfomation**: Provide the detail information for UVs and models.
